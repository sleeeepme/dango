再実行:


## 未解決問題と修正方針

### 1. ゆっくり上へドラッグすると浮く（優先度: 高）

足場上のy≈193から、80pxを120更新（60Hzなら2秒）かけて上へドラッグすると、y≈124へ約69px上昇する。そのまま180更新指を止めて保持するとy≈120で空中に留まる。解放時のジャンプ判定を抑えても、ドラッグ中の垂直追従が上昇を作る。

AGENTS.mdの「slow upward drag should not let it fly」と不一致。ドラッグ中は垂直方向の持ち上げを抑え、素早い上フリックの解放で跳ぶ挙動を維持する。

### 2. 緩い坂で静止位置が少しずつずれる（優先度: 高）

高さ13pxの坂の中央へ接地状態で配置すると、vx=0のまま600更新で下り方向に移動する。幅390では約7.64px、幅320では約9.31px、幅430では約6.73px。検証区間では停止せず、位置補正が継続する。

速度を0にする閾値だけでは、重力による侵入を斜めの法線方向へ押し戻す際の位置変化を止められない。接地状態と静止摩擦を導入し、無入力時は坂でも位置を保つ。能動的な移動、ジャンプ、天井反発との回帰を確認する。

### 3. 操作と物理が更新頻度に依存する（優先度: 高）

`requestAnimationFrame` ごとに一定量の加速・重力・移動を適用し、経過時間を使っていない。右ボタンを約0.25秒押す想定で30/60/120Hz相当の7/15/30更新を比較すると、変位は約10.91/43.85/151.47px。30Hzは整数丸めにより約0.233秒。120Hz相当では最初の足場を落ち始める。

固定時間ステップを使って操作・物理・アニメーションを揃える。背景復帰時に大量更新を実行しない上限も必要。

### 4. 画面回転時に地形幅が更新されない（優先度: 中）

390px幅で生成後、844pxへresizeしても地形の最大xは390のまま。CanvasとW/Hだけが更新され、地形と収集物の基準座標は初期幅のまま残る。

初期のワールド幅を固定して表示を変換するか、現在の進行位置と収集状態を保ちながら地形を再配置する。縦横両方向でプレイヤー位置と壁への接触も確認する。
